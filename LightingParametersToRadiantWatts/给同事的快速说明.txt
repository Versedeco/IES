## ⚡ 3步开始使用

### 第1步：运行程序

双击 `灯光参数转辐射瓦特计算器.exe`

**可能遇到Windows警告？**
- 点击"更多信息"
- 点击"仍要运行"
- 这是正常的安全提示

### 第2步：输入参数

在打开的窗口中：

1. **选择光源类型**
   - LED灯（最常用）
   - 白炽灯
   - 其他...

2. **输入流明值**
   - 从灯具产品规格书获取
   - 例如：1000

3. **输入色温**
   - 或点击快捷按钮
   - 2700K（暖光）
   - 4000K（中性光）
   - 6500K（冷光）

### 第3步：获取结果

1. 点击「🔄 计算辐射瓦特」按钮
2. 查看结果（例如：10.00 W）
3. 点击「📋 复制数值」复制
4. 在Blender中使用该值

---

## 💻 在Blender中使用

### 方法1：界面设置

1. 选择灯光对象
2. 属性面板 → Light Properties（灯泡图标）
3. 找到 Power 或 Energy
4. 输入计算结果

### 方法2：Python命令

```python
import bpy
light = bpy.context.active_object
light.data.energy = 10.00  # 替换为实际值
```

## 📝 实际例子

### 例子1：办公室筒灯

```
产品规格：
- LED筒灯
- 1000流明
- 4000K色温

步骤：
1. 光源类型：选"LED灯"
2. 流明值：输入 1000
3. 色温：点击 4000K

→ 在Blender中设置 Light.energy = 10.00
```

### 例子2：台灯

```

- 60W白炽灯泡
- 约800流明
- 2700K色温

1. 光源类型：选"白炽灯"
2. 流明值：输入 800
3. 色温：点击 2700K
4. 点击"计算"

结果：53.33 W
→ 在Blender中设置 Light.energy = 53.33
```

## ❓ 常见问题

**Q: 从哪里找流明值？**
A: 产品规格书、包装盒、灯具铭牌上查找"lm"或"流明"标记

**Q: 不知道色温怎么办？**
A:
- 暖光（黄色）→ 2700K
- 自然光（白色）→ 4000K
- 冷光（蓝白）→ 6500K

**Q: 结果为什么LED和白炽灯差这么多？**
A: 白炽灯大部分能量转化为热（红外辐射），LED几乎全是可见光

**Q: 需要网络吗？**
A: 不需要，完全离线运行

**Q: 需要安装吗？**
A: 不需要，双击EXE直接运行
