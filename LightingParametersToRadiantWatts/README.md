# 灯光参数转辐射瓦特计算器

**Lighting Parameters to Radiant Watts Calculator**

版本：v1.0  
日期：2026-01-21

---

## 📋 简介

这是一个简单易用的图形界面工具，用于将灯具厂商提供的参数（流明值、色温）转换为Blender所需的辐射瓦特(Radiant Watts)值。

---

## 🚀 快速开始

### 使用EXE文件（推荐）

1. 双击运行 `灯光参数转辐射瓦特计算器.exe`
2. 在界面中输入参数：
   - 选择光源类型（LED、白炽灯等）
   - 输入流明值（如1000）
   - 输入色温（如4000K）
3. 点击「计算辐射瓦特」按钮
4. 获得结果，在Blender中使用

### 使用Python脚本

如果你有Python环境：

```bash
python calculator_gui.py
```

## 💡 使用说明

### 输入参数

#### 1. 光源类型

选择灯具使用的光源类型：

- **LED灯** - 普通LED灯（光效80-150 lm/W）
- **高端LED灯** - 高端LED灯（光效120-200 lm/W）
- **白炽灯** - 传统白炽灯泡（光效10-20 lm/W）
- **卤素灯** - 卤素灯（光效15-25 lm/W）
- **荧光灯/节能灯** - 荧光灯或节能灯（光效50-80 lm/W）
- **金属卤化物灯** - 金卤灯（光效70-100 lm/W）
- **高压钠灯** - 高压钠灯（光效80-140 lm/W）

#### 2. 流明值 (lm)

- 灯具的总光通量
- 可从产品规格书获取
- 示例：500, 1000, 1500, 2000

#### 3. 色温 (K)

- 光源的色温
- **2700K** - 暖白光（温馨）
- **4000K** - 中性白光（自然）
- **6500K** - 冷白光（明亮）

## 💻 在Blender中使用

### 方法1：界面设置

1. 在Blender中选择灯光对象
2. 在属性面板找到Light设置
3. 找到"Power"或"Energy"参数
4. 输入计算器给出的辐射瓦特值

### 方法2：Python脚本

```python
import bpy

# 获取灯光对象
light = bpy.context.active_object

# 设置辐射瓦特（使用计算器的结果）
light.data.energy = 10.00  # 替换为实际计算值
```

## ❓ 常见问题

### Q: 为什么LED和白炽灯相同流明，辐射瓦特差异这么大？

**A**: 白炽灯大部分能量转化为红外热辐射（不可见光），LED几乎全部是可见光。因此：
- LED 1000流明 ≈ 10W 辐射瓦特
- 白炽灯 1000流明 ≈ 67W 辐射瓦特

### Q: 色温如何影响结果？

**A**: 人眼对不同波长光的敏感度不同：
- 高色温（冷光）光效更高，需要的辐射功率更少
- 低色温（暖光）光效较低，需要的辐射功率更多

示例（1000流明LED）：
- 2700K（暖光）→ 11.76 W
- 4000K（中性）→ 10.00 W
- 6500K（冷光）→ 9.09 W

### Q: 流明值从哪里获取？

**A**: 通常可以从以下途径获取：
- 灯具产品规格书
- 产品包装上的参数标签
- 制造商网站的产品页面
- 产品说明书

### Q: 计算结果准确吗？

**A**: 计算基于真实的光谱效率数据和物理原理，对于标准灯具准确度>95%。特殊灯具可能略有偏差。

## 📄 技术说明

### 核心算法

```
辐射瓦特 = 流明 / (最大光视效能 × 相对光效)

其中：
- 最大光视效能 = 683 lm/W（555nm单色光）
- 相对光效 = 实际光效 / 最大光视效能
- 实际光效会根据色温进行修正
```

### 色温修正系数

```
2700K: 0.85（暖光，光效较低）
3000K: 0.90
4000K: 1.00（基准）
5000K: 1.05
6500K: 1.10（冷光，光效较高）
```
