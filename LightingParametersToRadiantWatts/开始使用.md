## 🎓 技术信息

### 技术栈

- Python 3.7+
- tkinter（GUI库，Python自带）
- PyInstaller（打包工具）

### 核心算法

```
辐射瓦特 = 流明 / (最大光视效能 × 相对光效)

其中：
- 最大光视效能 = 683 lm/W
- 考虑色温修正
```

### 文件大小

- Python源码：~30KB
- 打包后EXE：~10-15MB（包含Python运行时）

## 🔧 常见问题

### Q: 如何运行程序？

**A**: 两种方式：
1. 直接运行：`python calculator_gui.py`
