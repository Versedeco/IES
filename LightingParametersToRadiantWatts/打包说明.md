# 打包说明

## 🎯 打包成EXE的步骤

### 前提条件

确保已安装Python（建议Python 3.7或更高版本）

### 步骤1：安装PyInstaller

打开命令提示符（CMD）或PowerShell，执行：

```bash
pip install pyinstaller
```

### 步骤2：执行打包

#### 方法A：使用打包脚本（推荐）

双击运行 `build.bat` 文件。

#### 方法B：手动执行命令

在当前目录下打开命令提示符，执行：

```bash
pyinstaller --name="灯光参数转辐射瓦特计算器" --onefile --windowed calculator_gui.py
```

### 步骤3：获取EXE文件

打包完成后，在 `dist` 文件夹中找到：

```
dist/灯光参数转辐射瓦特计算器.exe
```

### 步骤4：分发给同事

将以下文件/文件夹打包分享：

```
分享包/
├── 灯光参数转辐射瓦特计算器.exe  ← 从dist文件夹复制
├── README.md                      ← 说明文档
└── 使用指南.md                    ← 详细指南
```

## 🔧 打包参数说明

```bash
pyinstaller \
    --name="灯光参数转辐射瓦特计算器"  # EXE文件名
    --onefile                           # 打包成单个EXE
    --windowed                          # 无控制台窗口
    calculator_gui.py                   # 源文件
```

## ⚠️ 常见问题

### Q: 打包后EXE很大（>10MB）？

**A**: 正常现象。PyInstaller会打包Python解释器和所有依赖，导致文件较大。

### Q: Windows Defender报警？

**A**: 正常安全警告。可以：
1. 点击"更多信息"
2. 选择"仍要运行"
3. 或将EXE添加到信任列表

### Q: 打包失败？

**A**: 检查：
1. Python版本是否≥3.7
2. PyInstaller是否安装成功
3. 是否在正确的目录执行命令

### Q: 想要自定义图标？

**A**: 修改打包命令：

```bash
pyinstaller --name="灯光参数转辐射瓦特计算器" --onefile --windowed --icon=myicon.ico calculator_gui.py
```

需要准备一个 `.ico` 格式的图标文件。
