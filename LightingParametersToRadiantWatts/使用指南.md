## 安装与启动

### 方法1：使用EXE文件（推荐）✅

## 使用步骤

### 步骤1：选择光源类型

点击"光源类型"下拉框，选择你的灯具类型：

| 类型 | 说明 | 何时选择 |
|-----|------|---------|
| LED灯 | 普通LED | 大多数现代LED灯具 |
| 高端LED灯 | 高端LED | 高性能、高显指LED |
| 白炽灯 | 传统灯泡 | 老式白炽灯泡 |
| 卤素灯 | 卤素灯 | 射灯、车灯 |
| 荧光灯/节能灯 | 荧光灯 | 节能灯、T5/T8灯管 |
| 金属卤化物灯 | 金卤灯 | 商业照明、广场灯 |
| 高压钠灯 | 钠灯 | 路灯、工业照明 |

**提示**：下拉框下方会显示该类型的详细说明。

### 步骤2：输入流明值

在"流明值"框中输入数字：

**从哪里获取流明值？**

1. **产品规格书**
   ```
   示例：
   型号：LED-DL-1000
   功率：10W
   光通量：1000 lm  ← 这就是流明值
   色温：4000K
   ```

2. **产品包装**
   - 查找"lm"或"流明"标记
   - 通常在技术参数部分

3. **产品铭牌**
   - 灯具底部或侧面的标签
   - 查找"Luminous Flux"或"光通量"

**常见流明值范围**：
- 小夜灯：50-200 lm
- 台灯：300-800 lm
- 筒灯：500-1500 lm
- 吊灯：1000-3000 lm
- 投光灯：3000-10000 lm

### 步骤3：输入色温

在"色温"框中输入数字，或点击快捷按钮：

| 色温 | 光色 | 适用场景 |
|-----|------|---------|
| 2700K | 暖白光 | 卧室、餐厅、温馨场所 |
| 3000K | 暖白光 | 客厅、酒店 |
| 4000K | 中性白光 | 办公室、商店 |
| 5000K | 日光白 | 工厂、仓库 |
| 6500K | 冷白光 | 实验室、医院 |

**快捷按钮**：
- 点击 `2700K` - 设置为暖光
- 点击 `4000K` - 设置为中性光
- 点击 `6500K` - 设置为冷光

### 步骤4：计算

点击 `🔄 计算辐射瓦特` 按钮。

### 步骤5：查看结果

结果会显示在"计算结果"区：

```
辐射瓦特: 10.00 W
Blender设置: Light.energy = 10.00
```

### 步骤6：使用结果

- 点击 `📋 复制数值` 复制数值到剪贴板
- 在Blender中使用该值

## 在Blender中使用

### 方法1：属性面板设置（简单）

1. **选择灯光对象**
   - 在3D视图中点击灯光
   - 或在大纲视图中选择

2. **找到Light属性**
   - 右侧属性面板
   - 点击灯泡图标（Light Properties）

3. **设置Power/Energy**
   - 找到"Power"或"Energy"参数
   - 输入计算器给出的数值
   - 例如：`10.00`

### 方法2：Python脚本（精确）

```python
import bpy

# 获取当前选中的对象
obj = bpy.context.active_object

# 确保是灯光对象
if obj and obj.type == 'LIGHT':
    # 设置辐射瓦特
    obj.data.energy = 10.00  # 替换为实际值
    print(f"灯光 '{obj.name}' 已设置为 {obj.data.energy} W")
else:
    print("请先选择一个灯光对象")
```

### 方法3：批量设置多个灯

```python
import bpy

# 定义不同灯光的辐射瓦特
light_settings = {
    "主灯": 15.00,
    "辅助灯": 8.00,
    "装饰灯": 3.00,
}

# 批量设置
for light_name, watts in light_settings.items():
    if light_name in bpy.data.objects:
        light = bpy.data.objects[light_name]
        if light.type == 'LIGHT':
            light.data.energy = watts
            print(f"✅ {light_name}: {watts} W")
```

### 验证设置

设置后，可以通过以下方式验证：

```python
import bpy

light = bpy.context.active_object
print(f"当前灯光能量: {light.data.energy} W")
```

## 常见问题

### Q1: 计算器显示"输入错误"？

**A**: 检查输入值：
- 流明值必须是正数
- 色温范围：1000K - 10000K
- 不要输入文字或特殊符号

### Q2: 相同流明，不同光源类型结果差异大？

**A**: 这是正常的！不同光源的光谱效率差异很大：

```
1000流明的辐射瓦特对比：
- 高端LED：6.67 W
- 普通LED：10.00 W
- 荧光灯：15.38 W
- 白炽灯：66.67 W

原因：白炽灯大部分能量是红外热辐射
```

### Q3: 色温改变，结果也变化？

**A**: 是的！色温影响光效：

```
1000流明LED，不同色温：
- 2700K（暖光）：11.76 W
- 4000K（中性）：10.00 W
- 6500K（冷光）：9.09 W

原因：人眼对不同波长光的敏感度不同
```

### Q4: 我的灯具参数没有流明值？

**A**: 如果只有电功率（瓦特），可以估算：

```
估算流明值：
LED灯：瓦特 × 100
例如：10W LED ≈ 1000 lm

白炽灯：瓦特 × 15
例如：60W 白炽灯 ≈ 900 lm

荧光灯：瓦特 × 65
例如：18W 荧光灯 ≈ 1170 lm
```

### Q5: Blender中设置后场景还是太暗/太亮？

**A**: 可能的原因：

1. **场景比例问题**
   - 确保场景单位是米
   - 检查灯具距离

2. **曝光设置**
   - 调整相机的曝光（Exposure）
   - 检查色彩管理设置

3. **流明值不准确**
   - 重新确认产品规格
   - 尝试不同的流明值

4. **灯具遮挡**
   - 检查灯罩/反射器是否正确
   - 确保光线可以射出

### Q6: 可以保存计算历史吗？

**A**: 当前版本不支持。建议：
- 使用"详细信息"区的文本
- 复制粘贴到文本文件保存
- 或截图保存结果

### Q7: 可以离线使用吗？

**A**: 可以！这个工具完全离线运行，不需要网络连接。

## 技术原理

### 核心转换公式

```
辐射瓦特 = 流明 / (最大光视效能 × 相对光效)

其中：
- 最大光视效能 = 683 lm/W（555nm单色光）
- 相对光效 = (实际光效 × 色温系数) / 最大光视效能
```

### 光视效能（Luminous Efficacy）

不同光源的典型光效：

| 光源 | 光效 (lm/W) | 说明 |
|-----|------------|------|
| 高端LED | 150 | 最高效 |
| 普通LED | 100 | 现代主流 |
| 荧光灯 | 65 | 节能 |
| 卤素灯 | 20 | 较低效 |
| 白炽灯 | 15 | 最低效 |

### 色温修正系数

基于CIE标准色度学：

```
色温 → 修正系数
2700K → 0.85
3000K → 0.90
4000K → 1.00 (基准)
5000K → 1.05
6500K → 1.10
```

高色温（冷光）光效更高，因为人眼对蓝-绿光更敏感。

### 为什么白炽灯辐射瓦特高？

白炽灯的能量分布：
```
100% 电能
├─ 5% 转为可见光
└─ 95% 转为红外热辐射

因此：
- 可见光：800 lm
- 辐射功率：60W × 0.95 ≈ 57W（包含大量红外）
```

LED的能量分布：
```
100% 电能
├─ 30-40% 转为光辐射（几乎全是可见光）
└─ 60-70% 转为热（通过散热器散出，不是辐射）

因此：
- 可见光：1000 lm
- 辐射功率：10W × 0.35 ≈ 3.5W（几乎全是可见光）
```
