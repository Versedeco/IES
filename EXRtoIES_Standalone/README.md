## 📋 简介

独立的图形界面工具，用于将EXR光照分布文件转换为标准IES光度文件。

✨ **v2.1更新**：
- 🐛 **修复UE导入** - 解决"V Values are not in increasing order"错误
- ✅ **完美兼容** - 支持UE 4.x/5.x无缝导入
- 📏 **标准合规** - 严格遵循IES-LM-63格式

✨ **v2.0核心功能**：
- 🎨 **专业可视化** - 6种IES配光曲线图表
- 📊 **3D配光曲线** - 真实的3D空间光分布
- 📈 **光度统计** - 自动分析配光特性

支持任何来源的EXR文件：
- ✅ Blender烘焙的EXR
- ✅ 3ds Max / V-Ray渲染的EXR
- ✅ Corona Renderer的EXR
- ✅ Arnold / Redshift等

## 💡 使用说明

### 步骤1：选择EXR文件

点击"📂 浏览..."按钮，选择你的EXR文件。

**EXR要求**：
- Equirectangular全景格式（2:1比例）
- 球坐标UV映射
- 32位或16位浮点

### 步骤2：输入参数

#### 必需参数

**流明值 (lm)**
- 灯具的总光通量
- 例如：1000, 1500, 2000
- 可从产品规格书获取

**测量距离 (m)** ⚠️ 最重要！
- **必须与EXR烘焙时的球体半径一致**
- 如果EXR从5米半径球体烘焙 → 输入 5.0
- 错误的距离会导致IES光强不正确

**IES分辨率**
- 粗糙 (36×18)：快速预览
- **标准 (72×36)**：推荐
- 精细 (144×72)：高精度
- 超精细 (360×180)：科研级

#### 可选参数（IES文件头）

所有字段都有默认值，可以不修改：

- 制造商：默认 "Custom Lighting"
- 产品编号：默认 "EXR-GENERATED"
- 灯具名称：默认 "Generated from EXR"
- 灯泡描述：默认 "LED Light Source"
- 其他信息：默认 "Generated by EXR to IES Converter"
- 灯具尺寸：默认 0.15×0.15×0.10 (m)

### 步骤3：转换

1. 点击"🔄 开始转换"按钮
2. 观察日志窗口（显示转换进度）
3. 选择IES文件保存位置
4. 转换完成！

## 📊 使用示例

### 示例1：Blender烘焙的EXR

```
EXR文件：downlight_distribution.exr
烘焙参数：球体半径5米

转换参数：
  流明值：1000 lm
  测量距离：5.0 m  ← 与球体半径一致
  IES分辨率：标准 (72×36)
  
输出：downlight_1000lm.ies
```

### 示例2：3ds Max渲染的EXR

```
EXR文件：vray_light.exr
渲染参数：球体半径10米

转换参数：
  流明值：1500 lm
  测量距离：10.0 m  ← 与球体半径一致
  IES分辨率：精细 (144×72)
  
  制造商：Custom Studio
  产品编号：LIGHT-001
  灯具名称：Studio Light 1500lm
  
输出：studio_light_1500lm.ies
```

### 示例3：批量生成不同亮度版本

**关键技巧**：同一个EXR可以生成多个不同流明的IES！

```
使用同一个EXR文件：base_light.exr

第1次转换：
  流明值：500 lm
  → 生成 light_500lm.ies

第2次转换：
  流明值：1000 lm
  → 生成 light_1000lm.ies

第3次转换：
  流明值：1500 lm
  → 生成 light_1500lm.ies

所有IES配光形状相同，只是亮度不同！
```

## ⚠️ 重要提示

### 测量距离最关键！

**错误示例**：
```
EXR从5米半径球体烘焙
但转换时输入距离：10米
→ IES光强会错误（减半）
```

**正确示例**：
```
EXR从5米半径球体烘焙
转换时输入距离：5米
→ IES光强正确 ✅
```

### EXR格式要求

✅ **正确的EXR格式**：
- Equirectangular（等距柱状投影）
- 2:1宽高比（如4096×2048）
- 球坐标UV映射

❌ **不支持的格式**：
- 立方体贴图（Cubemap）
- 鱼眼投影
- 任意视角渲染

### 流明值可以修改

流明值**不需要**与EXR烘焙时一致：
- EXR记录的是归一化的配光分布
- 流明值只影响绝对亮度
- 可以自由修改

## ❓ 常见问题

### Q: 提示"需要安装OpenEXR或Pillow"？

**A**: 安装其中之一：
```bash
pip install OpenEXR
# 或
pip install Pillow
```

### Q: IES在CG软件中太暗/太亮？

**A**: 检查两个参数：
1. 测量距离是否正确（最常见原因）
2. 流明值是否准确

### Q: 转换后的IES配光不对？

**A**: 检查EXR格式：
- 必须是Equirectangular格式
- 宽高比应该是2:1
- 使用图像查看器确认

### Q: 可以处理任何EXR吗？

**A**: 只能处理：
- ✅ 光照分布EXR（球坐标映射）
- ❌ 不能处理普通渲染图

### Q: 测量距离如何确定？

**A**: 根据EXR生成方式：
- Blender：查看球体对象的半径
- 3ds Max：查看球体的Radius参数
- 记录在渲染笔记中（推荐）

## 🎓 技术原理

### 核心转换公式

```
IES光强 (cd/klm) = (EXR辐照度 × 距离²) / 流明 × 1000

关键：
- 距离平方反比定律
- 归一化为cd/klm
```

### 为什么测量距离重要？

```
假设真实情况：
  球体半径：5米
  实际辐照度：0.01 W/m²
  
计算光强：
  I = 0.01 × 5² = 0.25 W/sr

如果输入错误距离10米：
  I = 0.01 × 10² = 1.00 W/sr
  ❌ 错误：是真实值的4倍！
```
