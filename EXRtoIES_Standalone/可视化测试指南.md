### 常见错误排查

**错误1: ModuleNotFoundError: No module named 'matplotlib'**
```bash
pip install matplotlib
```

**错误2: 图表显示空白**
- 检查EXR文件是否有效
- 查看转换日志中的坎德拉值域
- 如果全为0，检查测量距离参数

**错误3: 3D图表无法旋转**
- 确认matplotlib后端为TkAgg
- 更新matplotlib: `pip install --upgrade matplotlib`

**错误4: 中文显示乱码**
- 正常现象（部分Windows系统）
- 不影响功能使用
