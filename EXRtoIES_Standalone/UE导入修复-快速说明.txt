# IES-UE导入错误已修复 - 快速说明

## 问题
之前生成的IES文件在UE中导入时报错：
```
❌ IES import failed: "V Values are not in increasing order"
```

## 解决方案
✅ **已在v2.1版本中修复！**

## 如何使用

### 方式1：运行EXE（推荐）
1. 双击：`dist\EXR_to_IES_Converter.exe`
2. 选择EXR文件
3. 填写参数后点击"转换"
4. 导入生成的IES到UE → ✅ 成功！

### 方式2：Python脚本
```bash
python exr_to_ies_gui.py
```

## 修复内容
- ✅ 角度自动排序（0° → 180°/360°）
- ✅ 符合IES-LM-63标准
- ✅ UE完美兼容

## 验证方法
1. 打开生成的IES文件
2. 检查角度行是否递增：
   ```
   水平角: 0.0 15.0 30.0 ... 360.0  ✅
   垂直角: 0.0 5.0 10.0 ... 180.0   ✅
   ```
3. 在UE中导入测试 → 无错误提示
