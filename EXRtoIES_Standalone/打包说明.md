# 打包说明

## 📦 如何打包成EXE (带可视化功能)

### 前提条件

1. Python 3.7+已安装
2. 必需的库已安装

### 步骤1：安装依赖

**基础依赖**:
```bash
pip install numpy pillow pyinstaller
```

**可视化依赖** (强烈推荐):
```bash
pip install matplotlib
```

**可选** (更好的EXR支持):
```bash
pip install OpenEXR
```

**一键安装所有依赖**:
```bash
pip install -r requirements.txt
```

### 步骤2：执行打包

#### 方法A：使用脚本（推荐）

双击运行 `build.bat`

#### 方法B：命令行

```bash
cd D:\TestLighting\EXR_to_IES\EXRtoIES_Standalone
build.bat
```

#### 方法C：手动命令（基础版，无可视化）

```bash
pyinstaller --name="EXR转IES转换器" --onefile --windowed exr_to_ies_gui.py
```

#### 方法D：手动命令（完整版，含可视化）

```bash
pyinstaller --name="EXR转IES转换器" ^
    --onefile ^
    --windowed ^
    --hidden-import=matplotlib ^
    --hidden-import=matplotlib.backends.backend_tkagg ^
    --hidden-import=mpl_toolkits.mplot3d ^
    --collect-data matplotlib ^
    exr_to_ies_gui.py
```

### 步骤3：获取EXE

打包完成后，在 `dist` 文件夹中：

```
dist/EXR转IES转换器.exe
```

### 步骤4：测试EXE

双击运行，确保功能正常。

**测试清单**:
- [ ] 程序正常启动
- [ ] 可以选择EXR文件
- [ ] 转换功能正常
- [ ] 可以保存IES文件
- [ ] 📊 可视化按钮可用
- [ ] 图表正常显示

### 步骤5：准备分发

创建分享包：

```
分享包/
├── EXR转IES转换器.exe      ← 从dist复制
├── README.md                ← 从当前目录复制
├── 给同事的快速说明.txt     ← 从当前目录复制
└── （可选）OpenEXR安装说明
```

## ⚠️ 重要提示

### 关于matplotlib可视化功能

**问题**: PyInstaller打包matplotlib时可能遗漏某些文件

**解决方案**:

1. **使用完整打包命令** (见方法D)
   ```bash
   --hidden-import=matplotlib
   --hidden-import=matplotlib.backends.backend_tkagg
   --hidden-import=mpl_toolkits.mplot3d
   --collect-data matplotlib
   ```

2. **如果可视化仍无法使用**
   - 基础转换功能不受影响
   - 用户可以单独安装matplotlib查看可视化
   - 或使用Python脚本版本

3. **测试可视化功能**
   - 打包后必须测试可视化按钮
   - 确保6个图表都能正常显示
   - 如有问题，使用 `--debug all` 参数重新打包

### 关于EXR读取库

EXE**不包含**OpenEXR或Pillow：

**情况A：使用者已安装Python和库**
- 一切正常工作

**情况B：使用者未安装Python**
- 程序可以运行
- 但读取EXR会失败
- 需要提供库的安装说明

### 解决方案

**方案1：让用户安装库**（推荐）

提供说明：
```
安装OpenEXR：
pip install OpenEXR

或安装Pillow：
pip install Pillow
```

**方案2：静态链接（高级）**

使用 `--hidden-import` 参数：
```bash
pyinstaller --name="EXR转IES转换器" --onefile --windowed \
  --hidden-import=numpy \
  --hidden-import=PIL \
  exr_to_ies_gui.py
```

注意：OpenEXR很难静态链接

## 🔧 常见问题

### Q: 打包后EXE很大？

**A**: 正常。PyInstaller会打包Python运行时和numpy。

典型大小：15-25MB

### Q: Windows Defender报警？

**A**: 正常安全提示。可以：
1. 点击"更多信息"→"仍要运行"
2. 添加到排除列表

### Q: 打包失败？

**A**: 检查：
1. PyInstaller是否安装：`pip install pyinstaller`
2. 是否在正确目录
3. Python版本是否≥3.7

### Q: EXE运行但无法读取EXR？

**A**: 使用者需要安装：
```bash
pip install OpenEXR
# 或
pip install Pillow
```

## 📝 打包选项说明

```bash
--name="..."      # EXE文件名
--onefile         # 打包成单个文件
--windowed        # 无控制台窗口
--icon=xxx.ico    # 自定义图标（可选）
--hidden-import   # 强制包含某个库
```
