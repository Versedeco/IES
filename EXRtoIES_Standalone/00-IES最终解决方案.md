## 🔍 问题根源（经过三个文件对比分析）

### 对比的三个文件

1. **TD_5w_D5M.ies** ✅ - 可导入UE（参考文件）
2. **TD_5w_D5M_New.ies** ❌ - 无法导入（旧版v2.0生成）

### 发现的问题

通过详细对比，发现**两个关键问题**：

#### 问题1：缺少关键的尺寸倍数行 ⭐ **最重要！**

**可导入的文件**（TD_5w_D5M.ies）：
```ies
行8:  1 5342 1.0 37 73 1 2 0.0 0.0 0.0
行9:  1.00 1.00 100.0                    ← ⭐ 关键行！
行10: 0.0                                 ← 开始角度数据
```

**无法导入的文件**（v2.0生成）：
```ies
行9:  1 1000.0 1.0 72 36 1 2 0.150 0.150 0.100
行10: 0.0 5.1 10.1 ... 360.0              ← ❌ 缺少第9行，直接到角度
```

**第9行含义**：
- `1.00` - 灯具宽度倍数
- `1.00` - 灯具长度倍数  
- `100.0` - 测量距离（米）

**重要性**：
- 这行将数据行与角度数据分隔开
- UE需要这行来正确识别后续数据的开始位置
- IES-LM-63-1995标准格式的必需部分

---

#### 问题2：角度值格式

**可导入格式**：每个角度占一行
```ies
0.0
5.0
10.0
...
```

**无法导入格式**：所有角度在一行
```ies
0.0 5.1 10.1 15.2 ... 360.0
```

## 🎯 关键知识点

### IES-LM-63格式的关键行

1. **标准版本行**：`IESNA:LM-63-1995` 或 `IESNA:LM-63-2002`
2. **元数据行**：`[TEST]`, `[MANUFAC]`, `[DATE]` 等
3. **TILT行**：`TILT=NONE`
4. **数据行**：`1 流明 1.0 H角数 V角数 类型 2 宽 长 高`
5. **⭐ 尺寸倍数行**：`宽度倍数 长度倍数 测量距离` - **极其重要！**
6. **角度数据**：水平角，然后垂直角
7. **光强数据**：按C平面→V角顺序

### UE的IES解析要求

- ✅ 必须有尺寸倍数行（第9行）
- ✅ 角度数据量大时，必须每行一个值
- ✅ 推荐使用IES-LM-63-1995标准
- ✅ 光强数据建议每行一个值（最安全）
