# IES可视化功能说明

## 📊 新增功能概述

EXR转IES转换器 v2.0 新增了专业的IES配光曲线可视化功能，可以在转换完成后直观地查看灯具的光分布特性。

## 🎨 六大可视化图表

### 1. 3D极坐标配光曲线 (3D Polar Distribution)
- **功能**: 显示灯具在三维空间中的真实光强分布
- **特点**: 
  - 使用极坐标系统展示
  - 半径表示归一化光强
  - 彩色曲线便于观察不同方向的光强
- **用途**: 直观了解灯具的整体配光特性

### 2. 水平配光图 (Horizontal Distribution)
- **功能**: 显示灯具在水平面（γ=90°）的光分布
- **特点**:
  - 极坐标俯视图
  - 显示C平面（0-360度）的光强变化
  - 填充区域表示光分布范围
- **用途**: 判断灯具是否为轴对称配光，查看水平光斑形状

### 3. 垂直配光图 - 主平面 (Vertical Distribution C0-C180)
- **功能**: 显示主平面（C0-C180）的垂直光分布
- **特点**:
  - 极坐标侧视图
  - 显示垂直角度（γ=0-180度）的光强
  - 对比C0和C180的光分布
- **用途**: 查看灯具向下和两侧的光分布情况

### 4. 光强分布热图 (Intensity Map)
- **功能**: 以伪彩色显示完整的光强分布
- **特点**:
  - X轴：水平角度（C角）
  - Y轴：垂直角度（γ角）
  - 颜色：光强大小（cd/klm）
  - jet色图：蓝色（低）→ 红色（高）
- **用途**: 快速识别光斑位置、形状和强度分布

### 5. 多平面垂直配光 (Multi-plane Vertical)
- **功能**: 同时显示8个C平面的垂直配光曲线
- **包含平面**: C0°, C45°, C90°, C135°, C180°, C225°, C270°, C315°
- **特点**:
  - 彩虹色编码不同平面
  - 便于对比不同方向的光分布
- **用途**: 分析非对称配光灯具的特性

### 6. 光度数据统计 (Photometric Statistics)
- **显示信息**:
  - **基本信息**: 灯具名称、制造商、流明值
  - **配光数据**: 最大/最小/平均光强、标准差
  - **最大光强方向**: 水平角和垂直角位置
  - **数据点数**: 采样密度
  - **配光类型**: 轴对称性判断、光束角计算
- **用途**: 获取灯具的量化性能参数

## 🔧 使用方法

### 步骤1: 完成EXR到IES转换
1. 选择EXR文件
2. 输入必要参数（流明、测量距离等）
3. 点击"🔄 开始转换"按钮
4. 等待转换完成

### 步骤2: 查看可视化
1. 转换成功后，"📊 显示IES可视化"按钮会自动启用
2. 点击该按钮
3. 等待几秒钟生成图表
4. 在新窗口中查看6个专业图表

### 步骤3: 交互操作
- **缩放**: 使用matplotlib工具栏的放大镜工具
- **平移**: 使用平移工具移动视图
- **保存**: 点击保存按钮导出图表为PNG
- **旋转**: 3D图表可以用鼠标拖拽旋转视角

## 💡 专业术语解释

### C角度 (C-plane)
- 水平旋转角度，0-360度
- C0通常表示灯具的前方
- C90和C270表示左右两侧
- C180表示后方

### γ角度 (Gamma angle)
- 垂直角度，0-180度
- γ=0°: 光轴方向（向下）
- γ=90°: 水平方向
- γ=180°: 向上方向

### cd/klm (Candela per kilolumen)
- 每千流明的光强
- 归一化单位，与实际流明值无关
- 只反映光分布形状

### 光束角 (Beam Angle)
- 光强下降到最大值50%的角度范围
- 用于描述灯具的聚光性能
- 角度越小，光束越聚集

## ⚙️ 高级功能

### 自动对称性检测
程序会自动判断灯具是否为轴对称配光：
- 对比C0和C180的光分布相关性
- 相关系数 > 0.95 判定为轴对称

### 光束角计算
自动计算50%最大光强的光束角：
- 基于垂直方向的光强分布
- 适用于聚光类灯具
- 泛光灯可能显示较大的角度

### 数据统计
提供完整的统计信息：
- 最大/最小/平均光强
- 标准差（反映光分布均匀性）
- 采样点数（反映精度）

## 🔍 注意事项

1. **图表生成时间**
   - 高分辨率IES（如360×180）可能需要10-30秒
   - 标准分辨率（72×36）通常2-5秒

2. **内存占用**
   - 可视化会占用额外内存
   - 超精细分辨率可能需要更多RAM

3. **图表保存**
   - 使用matplotlib工具栏的保存功能
   - 推荐保存为PNG或PDF格式
   - 建议分辨率: 300 DPI

4. **颜色映射**
   - Jet色图：蓝→绿→黄→红（低到高）
   - Rainbow色图：用于多曲线区分

## 🆘 常见问题

### Q1: 提示"需要安装matplotlib"？
**A**: 运行以下命令安装：
```bash
pip install matplotlib
```

### Q2: 图表显示空白或错误？
**A**: 可能原因：
- matplotlib版本过低，建议升级到3.3+
- 数据异常（全为0或NaN）
- 检查转换日志是否有错误

### Q3: 3D图表无法旋转？
**A**: 确保使用matplotlib的交互式后端（TkAgg）

### Q4: 图表文字显示乱码？
**A**: Windows系统可能缺少中文字体：
- 使用默认字体配置
- 或安装SimHei等中文字体

### Q5: 可以自定义图表样式吗？
**A**: 可以修改源代码中的可视化参数：
- `IESVisualizer`类的各个绘图方法
- 颜色映射、线宽、字体大小等
