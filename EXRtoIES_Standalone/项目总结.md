## 💡 使用示例

### 基本使用

```
1. 运行程序
2. 点击"浏览"，选择EXR文件
3. 输入流明值：1000
4. 输入测量距离：5.0（与烘焙时球体半径一致）
5. 选择IES分辨率：标准
6. 点击"开始转换"
7. 选择保存位置
8. 完成！
```

### 自定义IES信息

```
在"IES文件头信息"部分：
- 制造商：输入 "My Company"
- 产品编号：输入 "LIGHT-001"
- 灯具名称：输入 "LED Downlight 1000lm"
- 其他字段可选

这些信息会写入IES文件头部
```

## ⚠️ 重要提示

### 测量距离

**最关键的参数！**

```
EXR烘焙时球体半径 = 测量距离

例如：
- Blender中球体半径5米 → 输入 5.0
- 3ds Max中球体半径10米 → 输入 10.0

错误的距离 = 错误的IES光强！
```

### EXR格式

```
✅ 支持：
- Equirectangular全景格式
- 2:1宽高比
- 球坐标UV映射
- 32位或16位浮点

❌ 不支持：
- 立方体贴图
- 鱼眼投影
- 普通渲染图
```

## 📊 技术特点

### 转换算法

```python
# 核心转换公式
irradiance = sample_exr(theta, phi)  # W/m²
intensity = irradiance × distance²     # W/sr
cd_per_klm = (intensity / lumens) × 1000  # cd/klm
```

### IES分辨率选项

| 选项 | 分辨率 | 角度步长 | 用途 |
|-----|--------|---------|------|
| 粗糙 | 36×18 | 10° | 快速预览 |
| **标准** | **72×36** | **5°** | **推荐** |
| 精细 | 144×72 | 2.5° | 高精度 |
| 超精细 | 360×180 | 1° | 科研级 |
