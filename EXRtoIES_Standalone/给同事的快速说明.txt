## ⚡ 快速开始（4步完成）

### 第1步：运行程序

双击 `EXR转IES转换器.exe`

**Windows警告？**
- 点击"更多信息"
- 点击"仍要运行"
- 正常安全提示

### 第2步：选择文件和输入参数

1. **点击"📂 浏览..."** 选择EXR文件

2. **输入流明值**
   - 从产品规格书获取
   - 例如：1000

3. **输入测量距离** ⚠️ 最重要！
   - **必须与EXR烘焙时的球体半径一致**
   - 例如：5.0
   - 不确定？问生成EXR的人

4. **选择IES分辨率**
   - 推荐：标准 (72×36)

5. **可选：修改IES文件头信息**
   - 制造商、产品编号等
   - 有默认值，可以不改

### 第3步：转换并保存

1. **点击"🔄 开始转换"**
2. **选择保存位置**（自动建议文件名）
3. 等待转换完成

### 第4步：查看配光曲线 ✨新功能

1. **点击"📊 显示IES可视化"** 按钮
2. 等待3-10秒生成图表
3. 在新窗口查看**6个专业配光图表**：
   - 🔵 3D配光曲线（可旋转）
   - 📊 水平配光图
   - 📈 垂直配光图
   - 🎨 光强分布热图
   - 📉 多平面对比
   - 📋 统计信息

**图表操作**：
- 🖱️ 左键拖拽：旋转3D图
- 🔍 工具栏：缩放、保存图表


1. 点击"🔄 开始转换"
2. 选择保存位置
3. 完成！

## 📝 实际例子

### 例子1：Blender烘焙的EXR

```
你有一个EXR文件：downlight.exr
```

## ⚠️ 重要提示

### 测量距离必须正确！

这是最容易出错的地方：

```
❌ 错误：
EXR从5米球体烘焙，但输入距离10米
→ IES亮度会错误！

✅ 正确：
EXR从5米球体烘焙，输入距离5米
→ IES亮度正确！
```

**不确定距离？** 问生成EXR的人！

### 流明值可以随意改

好消息：流明值不需要与烘焙时一致

```
同一个EXR可以生成多个IES：
- 转换1次：流明500  → light_500lm.ies
- 转换2次：流明1000 → light_1000lm.ies
- 转换3次：流明1500 → light_1500lm.ies

配光形状相同，只是亮度不同！
```

## ❓ 常见问题

**Q: 从哪里获取EXR文件？**
A:
- Blender：烘焙光照分布到EXR
- 3ds Max：渲染带VRayLightMtl的球体
- Corona：渲染LightMtl球体
- 或从同事那里获取

**Q: 测量距离不确定怎么办？**
A:
- 查看Blender/3ds Max中的球体半径
- 问生成EXR的人
- 查看渲染笔记

**Q: 提示缺少库？**
A:
```bash
pip install OpenEXR
# 或
pip install Pillow
```

**Q: IES太暗/太亮？**
A:
1. 检查测量距离是否正确
2. 修改流明值重新转换

**Q: 需要网络吗？**
A: 不需要，完全离线运行

**Q: 需要安装吗？**
A: 不需要，双击EXE直接用

## 🎓 技巧

### 技巧1：批量生成不同亮度

```
有一个EXR：base.exr

多次运行程序，每次输入不同流明值：
- 第1次：500 lm  → light_500.ies
- 第2次：1000 lm → light_1000.ies
- 第3次：2000 lm → light_2000.ies

节省烘焙时间！
```

### 技巧2：自定义IES信息

```
如果要分享IES给客户：
1. 修改"制造商"为公司名
2. 修改"产品编号"为产品代码
3. 修改"灯具名称"为产品名

生成的IES会包含这些信息
```
