## 🔬 智能分析功能

### 自动检测和计算

1. **对称性检测**
   ```
   算法：对比C0和C180平面的相关系数
   判定：相关性 > 0.95 = 轴对称
   结果：自动显示"轴对称"或"非对称"
   ```

2. **光束角计算**
   ```
   定义：50%最大光强的角度范围
   方法：垂直方向光强阈值分析
   应用：快速判断聚光/泛光特性
   ```

3. **最大光强定位**
   ```
   自动找到：
   - 水平角度（C角）
   - 垂直角度（γ角）
   - 光强数值（cd/klm）
   ```

4. **统计数据**
   ```
   - 最大光强
   - 最小光强
   - 平均光强
   - 标准差（均匀性指标）
   ```
