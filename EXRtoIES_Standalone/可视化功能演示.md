# IES可视化功能演示指南

## 🎨 功能亮点

EXR转IES转换器 v2.0 新增了**专业级IES配光曲线可视化**功能，可以直观地展示灯具的光学性能。

## 📸 可视化效果展示

转换完成后点击"📊 显示IES可视化"按钮，将弹出包含**6个专业图表**的分析窗口：

```
┌─────────────────────────────────────────────────────────────┐
│          IES光度分析 - [灯具名称]                            │
├──────────────────┬──────────────────┬─────────────────────────┤
│  1. 3D配光曲线   │  2. 水平配光图   │  3. 垂直配光图(C0-180)  │
│  (3D Polar)      │  (Horizontal)    │  (Vertical)             │
│                  │                  │                         │
│  [3D球形曲线]    │  [极坐标俯视]    │  [极坐标侧视]           │
├──────────────────┼──────────────────┼─────────────────────────┤
│  4. 光强分布热图 │  5. 多平面配光   │  6. 光度统计信息        │
│  (Intensity Map) │  (Multi-plane)   │  (Statistics)           │
│                  │                  │                         │
│  [伪彩色热图]    │  [8个C平面对比]  │  [数据分析表格]         │
└──────────────────┴──────────────────┴─────────────────────────┘
```

## 🔬 六大图表详解

### 图表1: 3D极坐标配光曲线

**视觉效果**:
- 立体球形曲线，可用鼠标360°旋转观察
- 曲线颜色：蓝色(低光强) → 红色(高光强)
- 半径长度表示光强大小

**解读方法**:
```
✓ 对称的球形 = 全向均匀配光（如球泡灯）
✓ 下方突出的锥形 = 聚光配光（如射灯）
✓ 扁平的圆盘形 = 泛光配光（如工矿灯）
✓ 不规则形状 = 非对称配光（如路灯）
```

**应用场景**:
- 快速判断灯具配光类型
- 检查是否存在异常光斑
- 验证EXR转换是否正确

---

### 图表2: 水平配光图（俯视图）

**视觉效果**:
- 极坐标平面图
- 蓝色实线+半透明填充
- 显示γ=90°（水平面）的光分布

**解读方法**:
```
圆形 → 轴对称配光（如筒灯）
椭圆形 → 部分非对称（如线性灯）
不规则形 → 高度非对称（如投光灯）
多个峰值 → 多光束配光（如特殊灯具）
```

**关键参数**:
- **C角度**: 0°-360°，表示水平旋转方向
- **光强**: 径向距离表示该方向的光强

---

### 图表3: 垂直配光图（C0-C180平面）

**视觉效果**:
- 极坐标半圆图
- 两条曲线对比：C0°（前）和C180°（后）
- 角度范围：0°-180°

**解读方法**:
```
C0与C180重合 → 完全轴对称
向下集中 → 窄光束（如射灯）
向下展开 → 宽光束（如泛光灯）
向上有光 → 上抛光（如间接照明）
```

**专业术语**:
- **γ=0°**: 光轴方向（正下方）
- **γ=90°**: 水平方向
- **γ=180°**: 向上方向

---

### 图表4: 光强分布热图

**视觉效果**:
- 矩形热图，伪彩色显示
- X轴: 水平角度（C角，0-360°）
- Y轴: 垂直角度（γ角，0-180°）
- 颜色: 蓝(低) → 绿 → 黄 → 红(高)

**解读方法**:
```
查看主光斑位置:
- 底部中心 = 正下方主光束
- 底部两侧 = 侧向配光
- 顶部有色 = 上抛光

查看光分布均匀性:
- 颜色过渡平滑 = 光分布连续
- 出现孤立色块 = 可能存在问题
```

**高级应用**:
- 精确定位最大光强方向
- 识别光斑的形状和尺寸
- 对比不同EXR的配光差异

---

### 图表5: 多平面垂直配光

**视觉效果**:
- 极坐标半圆图
- 8条彩色曲线叠加
- 每条代表一个C平面：0°, 45°, 90°, 135°, 180°, 225°, 270°, 315°

**解读方法**:
```
所有曲线重合 → 完美轴对称
曲线略有差异 → 基本对称
曲线明显分离 → 非对称配光
特定方向突出 → 定向配光
```

**实用价值**:
- 轴对称性定量分析
- 非对称配光特征识别
- 配光一致性检查

---

### 图表6: 光度统计信息

**显示内容**:

#### 📋 基本信息
- 灯具名称、制造商
- 流明值（总光通量）

#### 📊 配光数据
```
最大光强: XXX cd/klm  ← 最亮点的光强
最小光强: XXX cd/klm  ← 最暗点的光强
平均光强: XXX cd/klm  ← 所有方向平均
标准差: XXX           ← 光分布均匀性指标
```

**标准差解读**:
- 小 → 光分布均匀（如球泡灯）
- 大 → 光分布集中（如射灯）

#### 🎯 最大光强方向
```
水平角 (C): XX°   ← 主光束的水平方向
垂直角 (γ): XX°   ← 主光束的垂直角度
```

常见值：
- C=0, γ=0 → 正前正下（常见筒灯）
- C=任意, γ≈20-40 → 投光角度（射灯）

#### 🔢 数据点数
```
水平采样: 72点   ← C角度的采样密度
垂直采样: 36点   ← γ角度的采样密度
总数据点: 2592点 ← 总采样点（精度）
```

#### ⚖️ 配光类型
```
对称性: 轴对称 / 非对称
光束角: XX°
```

**光束角定义**: 光强下降到最大值50%的角度范围
- 窄光束: < 20° (聚光射灯)
- 中光束: 20° - 40° (标准射灯)
- 宽光束: 40° - 80° (泛光灯)
- 超宽: > 80° (大面积照明)

## 🎓 实用案例分析

### 案例1: 验证射灯配光

**期望特征**:
- 3D曲线呈锥形，向下集中
- 垂直配光在γ=20-40°有峰值
- 光束角 < 40°
- 热图显示中心底部有明显红色区域

**检查清单**:
```
✓ 最大光强方向接近γ=0°（正下方）
✓ 光束角符合产品规格
✓ C0和C180曲线基本重合（轴对称）
✓ 无异常光斑或噪点
```

### 案例2: 验证路灯配光

**期望特征**:
- 3D曲线呈椭圆形，横向拉长
- 水平配光呈椭圆（长边对应道路方向）
- 多平面配光明显不对称
- 热图显示两侧有较强光分布

**检查清单**:
```
✓ 非对称配光明确
✓ 横向（C90/C270）光强大于纵向（C0/C180）
✓ 垂直角度集中在γ=60-80°（避免眩光）
✓ 配光符合道路照明标准
```

### 案例3: 验证全向灯泡

**期望特征**:
- 3D曲线接近球形
- 水平配光近似圆形
- 所有C平面曲线基本重合
- 统计信息显示"轴对称"

**检查清单**:
```
✓ 对称性判断为"轴对称"
✓ 标准差较小（光分布均匀）
✓ 最大光强方向无明显偏向
✓ 热图颜色分布均匀
```

## 🔍 问题诊断指南

### 问题1: 可视化显示空白或异常

**可能原因**:
1. EXR数据全为0
2. 测量距离参数错误
3. 坎德拉值超出合理范围

**解决方法**:
```
1. 查看转换日志中的"坎德拉值域"
2. 如果是[0.00, 0.00]，检查EXR文件
3. 如果值异常大/小，调整测量距离参数
4. 重新转换后再查看可视化
```

### 问题2: 3D图表变形或比例失调

**原因**: matplotlib版本或显示设置问题

**解决方法**:
```bash
# 更新matplotlib到最新版本
pip install --upgrade matplotlib
```

### 问题3: 中文显示为方块

**原因**: 系统缺少中文字体

**影响**: 仅显示问题，不影响功能

**解决方法**: 忽略或安装中文字体（可选）

### 问题4: 图表生成很慢

**原因**: IES分辨率过高（如360×180）

**优化方案**:
1. 使用"标准 (72×36)"分辨率预览
2. 确认配光正确后再用高分辨率
3. 关闭其他占用内存的程序

## 📚 专业术语速查

| 术语 | 英文 | 解释 |
|------|------|------|
| **C角度** | C-plane | 水平旋转角度，0-360° |
| **γ角度** | Gamma angle | 垂直角度，0-180° |
| **cd/klm** | Candela per kilolumen | 每千流明的光强 |
| **配光曲线** | Light Distribution Curve | 描述灯具光分布的曲线 |
| **光束角** | Beam Angle | 50%最大光强的角度范围 |
| **轴对称** | Axisymmetric | 沿光轴旋转对称 |
| **非对称** | Asymmetric | 不同方向光分布差异大 |
| **光通量** | Luminous Flux | 总光输出，单位流明(lm) |
| **光强** | Luminous Intensity | 特定方向的光密度，单位坎德拉(cd) |

## 🎯 最佳实践建议

### 工作流程建议

```
1. 转换 → 使用"标准"分辨率快速转换
         ↓
2. 可视化 → 查看6个图表，初步验证
         ↓
3. 调整 → 如有问题，调整参数重新转换
         ↓
4. 确认 → 配光正确后，使用"精细"分辨率
         ↓
5. 交付 → 保存IES文件和可视化图表
```

### 图表保存建议

**用于文档/报告**:
- 格式: PNG
- 分辨率: 300 DPI
- 尺寸: 16×10英寸（当前默认）

**用于演示/打印**:
- 格式: PDF
- 优点: 矢量图，缩放不失真
- 可在Adobe Illustrator等软件中编辑

**快速预览**:
- 截图即可
- 或保存为低分辨率PNG（100 DPI）

### 参数组合建议

| 应用场景 | 流明值 | 测量距离 | IES分辨率 |
|----------|--------|----------|-----------|
| 快速测试 | 1000 | 5.0m | 粗糙(36×18) |
| 标准工作 | 实际值 | 实际半径 | 标准(72×36) |
| 高精度 | 实际值 | 实际半径 | 精细(144×72) |
| 专业级 | 实际值 | 实际半径 | 超精细(360×180) |

## 🆘 常见问题FAQ

**Q: 可视化是必需的吗？**
A: 不是。转换功能独立运行，可视化是可选的辅助功能。

**Q: 没有matplotlib怎么办？**
A: 基础转换功能仍可用，安装matplotlib后即可使用可视化。

**Q: 可以只保存某一个图表吗？**
A: 可以。使用matplotlib工具栏的区域选择工具，或用截图工具。

**Q: 图表可以自定义样式吗？**
A: 可以修改源码中的`IESVisualizer`类来自定义颜色、字体等。

**Q: 可视化支持批量处理吗？**
A: 当前版本需要逐个查看，批量功能可在未来版本中添加。

**Q: 可以导出原始数据吗？**
A: IES文件本身就包含所有配光数据，可用专业软件（如DIALux）读取。
