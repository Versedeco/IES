# IES导入UE错误修复 - 测试验证指南

## 修复内容概述

已修复IES文件在Unreal Engine导入时的错误：
- ❌ 旧错误：`V Values are not in increasing order`
- ✅ 新版本：确保角度严格递增，符合IES-LM-63标准

## 测试步骤

### 步骤1：重新生成IES文件

#### 方法A：使用EXE程序
1. 双击运行：`dist\EXR_to_IES_Converter.exe`
2. 选择您的EXR文件（例如：`D:/TestLighting/TD_5w_D5M.exr`）
3. 填写必要参数（流明值等）
4. 点击"转换"按钮
5. 记录输出的IES文件路径

#### 方法B：使用Python脚本
```bash
cd D:\TestLighting\EXR_to_IES\EXRtoIES_Standalone
python exr_to_ies_gui.py
```

### 步骤2：验证IES文件格式

用文本编辑器打开生成的IES文件，检查以下内容：

#### 检查点1：文件头信息
```
IESNA:LM-63-2002
[MANUFAC] ...
[LUMCAT] ...
...
TILT=NONE
```

#### 检查点2：数据行
```
1 <流明值> 1.0 <水平角数> <垂直角数> <类型> 2 <宽> <长> <高>
```

#### 检查点3：水平角度（第一行角度数据）
**必须严格递增**，例如：
```
0.0 15.0 30.0 45.0 60.0 75.0 90.0 ... 345.0 360.0
```

#### 检查点4：垂直角度（第二行角度数据）
**必须严格递增**，例如：
```
0.0 5.0 10.0 15.0 20.0 ... 170.0 175.0 180.0
```

#### 检查点5：光强数据
数据应按以下顺序排列：
```
C0平面所有V角数据, C1平面所有V角数据, ...
```

### 步骤3：在UE中测试导入

#### 3.1 打开Unreal Engine项目

#### 3.2 导入IES文件
1. **Content Browser** → 右键 → **Import**
2. 选择新生成的IES文件
3. 等待导入完成

#### 3.3 检查导入结果

**✅ 成功标志：**
- Output Log中没有错误信息
- IES文件成功创建为 `TextureLightProfile` 资源
- 可以在Content Browser中看到光度文件图标

**❌ 失败标志：**
- Output Log显示：`IES import failed: "V Values are not in increasing order"`
- 或其他IES格式错误

#### 3.4 测试光照效果
1. 在场景中添加一个 **Point Light** 或 **Spot Light**
2. 在灯光属性中设置：
   - **IES Texture** → 选择导入的IES文件
   - **Use IES Intensity** → 勾选
3. 观察场景中的光照分布是否正确

### 步骤4：对比测试

如果有旧版本生成的IES文件，可以进行对比：

| 测试项 | 旧版本 | 新版本（修复后） |
|--------|--------|------------------|
| UE导入 | ❌ 失败 | ✅ 成功 |
| 角度顺序 | ❓ 未排序 | ✅ 严格递增 |
| 光照效果 | ⚠️ 无法测试 | ✅ 正常显示 |

## 常见问题排查

### Q1: 导入时仍然报错
**可能原因：**
- 使用了旧版本程序生成的IES
- EXR文件本身有问题

**解决方法：**
1. 确认使用修复后的程序（检查文件时间戳）
2. 重新生成IES文件
3. 检查EXR文件是否能正常打开

### Q2: IES可以导入但光照效果不对
**可能原因：**
- 流明值设置不正确
- 灯具类型参数不匹配

**解决方法：**
1. 检查IES文件头中的流明值
2. 调整UE中灯光的强度乘数
3. 确认灯具类型参数（Type A/B/C）

### Q3: 可视化预览正常但UE导入失败
**可能原因：**
- UE版本对IES格式要求更严格
- 某些特殊角度值导致问题

**解决方法：**
1. 查看UE的Output Log获取详细错误
2. 用IES验证工具检查文件格式
3. 联系技术支持并提供具体错误信息
